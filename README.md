# PDF 편집 뷰어

브라우저에서 PDF를 보고 편집한 뒤 새 PDF로 저장하는 웹 앱입니다.
파일은 브라우저 안에서만 처리되며 서버로 전송되지 않습니다.

## 실행

```bash
npm install
npm run dev       # 개발 서버 (http://localhost:5173)
npm run build     # dist/ 에 정적 파일 생성 — 아무 정적 호스팅에 올리면 됩니다
npm run preview   # 빌드 결과 미리보기
```

## 기능

**보기**
- PDF 열기 (버튼 또는 끌어다 놓기), 비밀번호가 걸린 PDF 지원
- 페이지 썸네일, 확대/축소(Ctrl+휠, Ctrl +/−), 폭 맞춤
- 화면에 보이는 페이지만 그려서 큰 문서도 가볍게 동작

**편집 도구**

| 도구 | 단축키 | 설명 |
|---|---|---|
| 선택 | V | 이동, 오른쪽 아래 핸들로 크기 조절, 텍스트는 더블클릭해 수정 |
| 텍스트 | T | 클릭한 곳에 글자 입력 (여러 줄, 한글 지원) |
| 글자 수정 | E | 문서의 기존 글자를 클릭하면 원래 글자를 흰색으로 가리고 같은 위치·크기로 고쳐 쓸 수 있음 |
| 펜 | P | 자유 그리기 |
| 형광펜 | H | 영역 강조 (곱하기 혼합이라 글자가 그대로 보임) |
| 사각형 / 원 / 선 | R / O / L | Shift: 정사각형·정원·45° 단위 |
| 지우개 | W | 영역을 흰색(또는 원하는 색)으로 가리기 |
| 이미지 | I | PNG·JPG 등 이미지 삽입 |

오른쪽 속성 패널에서 색, 채우기, 선 굵기, 불투명도, 글자 크기, 굵게를 바꿀 수 있습니다.
선택한 개체가 있으면 그 개체를, 없으면 도구 기본값을 바꿉니다.

**페이지 작업**: 회전, 순서 이동, 빈 페이지 추가, 삭제, 다른 PDF의 페이지 추가(병합)

**기타**: 실행 취소/다시 실행(Ctrl+Z / Ctrl+Y), 복제(Ctrl+D), 방향키 미세 이동, 저장(Ctrl+S).
Chrome·Edge에서는 저장 위치를 고르는 창이 뜨고, 다른 브라우저에서는 `원래이름_편집.pdf`로 내려받습니다.

## 구조

| 파일 | 역할 |
|---|---|
| `src/main.js` | 화면 구성, 렌더링, 마우스·키보드 조작, 실행 취소 기록 |
| `src/annotations.js` | 편집 개체(텍스트·도형·그림·이미지) 좌표 계산 |
| `src/save.js` | pdf-lib로 페이지를 새 순서로 복사하고 편집 내용을 그려 넣어 PDF 생성 |
| `src/text.js` | 글꼴 로드와 글자 크기 측정 (화면과 저장 결과가 같은 위치에 오도록 공유) |
| `src/sfnt.js` | 글꼴 파일을 PDF에 넣기 전에 정리 (아래 참고) |

- 화면 표시는 [PDF.js](https://mozilla.github.io/pdf.js/), 저장은 [pdf-lib](https://pdf-lib.js.org/)을 사용합니다.
- 편집 개체는 원본 PDF를 바꾸지 않고 페이지 위 별도 층(SVG)에 그려지며, 저장할 때 페이지 내용으로 합쳐집니다.
- 한글 표시를 위해 나눔고딕(SIL Open Font License)을 내장합니다. fontkit이 이 글꼴의 GSUB/GPOS 표를 읽지 못하고
  부분 글꼴(subset) 생성도 글자가 빠지는 문제가 있어, `sfnt.js`에서 해당 표를 빼고 사용하지 않는 글자 모양을 비운 뒤
  넣습니다. 그래서 저장 파일에는 실제로 쓴 글자만 담겨 크기가 작습니다.

## 알아 둘 점

- **글자 수정과 지우개는 가리기 방식입니다.** 원래 글자는 보이지 않게 덮일 뿐 PDF 안에 남아 있어 복사·검색될 수 있습니다.
  개인정보처럼 완전히 지워야 하는 내용에는 쓰지 마세요.
- 저장할 때 페이지를 새 문서로 복사하므로 입력 양식(AcroForm), 책갈피, 문서 정보는 유지되지 않습니다.
- 내장 글꼴(나눔고딕)에 없는 문자(예: à, é 같은 악센트 문자, 일부 기호)는 저장할 때 빠지며, 그 경우 저장 후 알려 줍니다.
- 스캔한 PDF는 글자 정보가 없어 글자 수정 도구가 동작하지 않습니다. 지우개와 텍스트 도구를 함께 쓰세요.
