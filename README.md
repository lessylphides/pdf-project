# PDF 편집기

스마트폰과 iPad에서 PDF를 열어 **글자 입력, 서명·도장, 형광펜·메모**를 넣고 새 PDF로 저장하는 웹 앱입니다.
설치 없이 Safari·Chrome에서 실행되며, 파일은 **기기 안에서만 처리**되고 어디에도 전송되지 않습니다.

주소: <https://lessylphides.github.io/pdf-project/>  (배포 방법은 아래 참고)

## 사용법

화면 아래의 **보기 · 편집 · 서명 · 주석 · 페이지** 탭에서 도구를 고릅니다.

| 탭 | 기능 |
|---|---|
| 보기 | 선택·이동, 확대/축소(두 손가락), 폭 맞춤, 페이지 이동, 페이지 목록 |
| 편집 | 텍스트 추가, 기존 글자 수정, 이미지, 펜, 사각형, 원, 선, 지우개(가리기) |
| 서명 | 서명 그리기(손가락·Apple Pencil 필압), 도장 만들기(이름 → 인감 모양), 사진으로 만들기(배경 자동 제거), 보관함 |
| 주석 | 형광펜, 밑줄(글자 줄에 자동으로 맞춤), 메모 |
| 페이지 | 페이지 목록(길게 눌러 끌면 순서 변경), 회전, 빈 페이지, 다른 PDF 추가, 삭제, 문자 인식 |

- **입력 칸이 있는 PDF**(신청서·계약서 양식)는 칸을 눌러 바로 입력합니다. 저장하면 실제 양식 값으로 기록됩니다.
- 넣은 개체는 눌러서 선택하고, 끌어서 옮기고, 오른쪽 아래 동그라미로 크기를 바꿉니다. 선택한 글자를 한 번 더 누르면 수정합니다.
- 위쪽 🔍 로 문서 안의 글자를 찾습니다(띄어쓰기·대소문자 무시).
- 위쪽 ⬆ 에서 **공유·인쇄**(iOS 공유 메뉴: 프린트, "파일"에 저장, 메시지), **다운로드**, **다른 이름으로 저장**을 고릅니다.
- 작업은 기기에 자동 저장되어, 창을 닫았다 열어도 **이어서 하기**로 계속할 수 있습니다.
- Safari 공유 메뉴의 **홈 화면에 추가**로 앱처럼 쓸 수 있고, 한 번 연 뒤에는 인터넷 없이도 열립니다.
- Apple Pencil을 쓰면 자동으로 "펜슬로만 그리기"가 켜져, 손가락은 화면 이동·펜슬은 그리기에 쓰입니다(메뉴에서 변경).

## 저장 방식

| 편집 | 저장되는 형태 |
|---|---|
| 텍스트, 도형, 펜, 이미지, 서명, 도장, 지우개 | 페이지 내용에 직접 그려짐 |
| 형광펜, 밑줄, 메모 | PDF 표준 주석 — 다른 PDF 앱에서도 주석으로 보이고 지울 수 있음 |
| 입력 칸 값 | PDF 양식 값 (한글 글꼴로 표시 모양까지 생성) |
| 문자 인식 결과 | 보이지 않는 글자 층 — 검색·복사 가능 |

- 저장 파일은 **PDF 1.7**입니다. 원본 파일은 바뀌지 않고, 편집본이 새 파일로 저장됩니다.
- 처음 연 파일을 바탕으로 저장하므로 **입력 칸·책갈피·문서 정보가 유지**됩니다.
  삭제한 페이지는 내용까지 파일에서 제거됩니다.

## 알아 둘 점

- **글자 수정과 지우개는 가리기 방식**입니다. 가려진 원래 글자는 파일 안에 남아 복사·검색될 수 있으니
  완전히 지워야 하는 개인정보에는 쓰지 마세요.
- **비밀번호 PDF**는 비밀번호를 입력해 열고, 저장한 파일에는 비밀번호가 없습니다(비밀번호 설정 기능은 없음).
  보안을 위해 비밀번호로 연 문서는 자동 저장하지 않습니다.
- 다른 PDF에서 추가한 페이지의 입력 칸은 보이기만 하고 입력할 수 없습니다.
- 전자서명(인증서)이 들어 있던 PDF는 편집하면 그 인증이 무효가 됩니다.
- 문자 인식은 처음 한 번 인식 데이터(약 6MB)를 받으며, 휴대폰에서는 한 쪽에 수십 초가 걸릴 수 있습니다.
- 내장 글꼴(나눔고딕)에 없는 문자는 저장할 때 빠지며, 그 경우 저장 후 알려 줍니다.

## 개발

```bash
npm install
npm run dev       # 개발 서버 (같은 Wi-Fi의 휴대폰에서도 접속 가능)
npm run build     # dist/ 에 배포용 파일 생성
npm test          # 빌드 결과를 휴대폰 화면 크기 브라우저에서 자동 검사 (Playwright 필요)
```

### GitHub Pages 배포

`.github/workflows/deploy.yml`이 `main` 브랜치에 올라올 때마다 빌드해서 게시합니다.
처음 한 번만 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꾸면 됩니다.

### 구조

| 파일 | 역할 |
|---|---|
| `src/main.js` | 화면, 렌더링, 터치·펜 조작, 도구, 검색, 저장·공유, 자동 저장 |
| `src/save.js` | pdf-lib로 원본을 바탕으로 페이지 재구성, 편집 내용·표준 주석·양식 값·OCR 글자 층 기록 |
| `src/sign.js` | 서명 패드, 도장 생성기, 사진 배경 제거 |
| `src/ocr.js` | Tesseract.js 문자 인식(한국어·영어) |
| `src/qpdf.js` | qpdf(WebAssembly)로 비밀번호 해제, 손상 파일 복구 |
| `src/storage.js` | IndexedDB: 자동 저장, 서명·도장 보관함 |
| `src/annotations.js`, `src/text.js`, `src/sfnt.js` | 편집 개체 좌표, 글꼴 측정, 글꼴 정리 |
| `src/ui.js`, `src/icons.js`, `src/style.css` | 하단 시트·알림, 아이콘, 스타일(시스템 밝기/어둡기 따름) |
| `scripts/copy-assets.mjs` | PDF.js·qpdf·OCR 실행 파일을 `public/vendor`로 복사(외부 CDN 미사용) |
| `tests/` | 테스트용 PDF 생성, 자동 검사 |

보안: 배포본에는 콘텐츠 보안 정책(CSP)이 들어가 이 사이트의 스크립트만 실행되며, PDF 안의 스크립트는 실행하지 않습니다.

사용한 오픈소스: PDF.js, pdf-lib, qpdf, Tesseract.js, 나눔고딕·나눔명조(SIL OFL).
